# Send It Storybook

Send It 是攀岩者的紀錄 App：查詢岩館與路線、記錄完攀、分享 Beta 影片。這裡是它的元件與畫面目錄，全部使用真實的 React Native 元件，資料為假資料。

## 側欄分類

- **Foundations**：Tokens（色彩、字級、間距）與 Icons。
- **Components**：21 個基礎 UI 元件，依字母排序。
- **Patterns**：12 個 Send It 專屬元件（RouteCard、AppHeader、TabBar 等）。
- **Pages**：完整畫面，放在 iPhone 外框內，附真實的 AppHeader 與浮動 TabBar。依 TabBar 分成 Home、Gyms、Profile、Settings & Notifications、Auth。
- Components 與 Patterns 的每個元件都有 Docs 頁，可一次看到所有 story 與屬性表。

## 工具列

- **Theme**：切換淺色與深色。
- **Language**：切換 zh-TW 與 en，預設 zh-TW。
- **Reduce Motion**：強制使用減少動態。
- **Speed**：把動畫放慢 3 倍或 10 倍，方便檢查。
- **Haptic log**：每次觸發觸覺回饋，畫布右上角會顯示 `haptic: <key>`，同時寫入 console。
